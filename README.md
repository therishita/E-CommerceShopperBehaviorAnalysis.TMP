# E-Commerce Shopper Behavior Analysis

## Problem Statement

This project focuses on analyzing e-commerce shopper behavior and lifestyle patterns using a dataset of 1,000,000 users. Through Exploratory Data Analysis (EDA), statistical techniques, and data visualization, the project aims to understand customer demographics, shopping habits, engagement, and purchasing behavior to uncover meaningful insights.

## Summary of Findings

- **Device Preference:** Mobile is the most commonly used device, accounting for 60.02% of users.
- **Country Distribution:** Brazil has the highest user representation at 10.05%, with users almost equally distributed across ten countries.
- **Education Level:** Bachelor's degree holders represent the largest group at 30%.
- **Employment Status:** All employment categories have a nearly equal distribution of approximately 20%.
- **Cart Abandonment:** The average cart abandonment rate is 40.21%.
- **Return Rate:** The average return rate is 50%.
- **Extreme Cart Abandonment:** 4.77% of users have cart abandonment rates above 80%.
